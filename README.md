# JournalApp – Role-Based System
<h1 align="center">
            JournalApp – Role-Based System
</h1>

> Designed and developed a journal management system with user and admin roles using Spring Boot, Java, and
APIs. 
-> Integrated MongoDB for persistence, Redis for caching, SonarQube for code quality, and JUnit for testing,
ensuring scalability, performance, and maintainability.
<br>
